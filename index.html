Mã nguồn Google Apps Script chuẩn (Tự tạo 4 Sheet)

Tự động khởi tạo: SanPham, DonHang, KhachHang, CauHinh

Hướng dẫn cập nhật Apps Script (4 Sheets):

  1. Mở file Google Sheets → Tiện ích mở rộng (Extensions) → Apps Script.
  2. Xóa code cũ và dán toàn bộ đoạn code bên dưới vào, sau đó nhấn Lưu (Ctrl+S).
  3. Nhấn Triển khai (Deploy) → Quản lý các tệp triển khai → biểu tượng cây bút (Chỉnh sửa) → Phiên bản: Phiên bản mới → Triển khai (nếu triển khai mới thì chọn Ứng dụng web, quyền truy cập: Bất kỳ ai).
  4. Dán đường dẫn URL ứng dụng web vào ô cấu hình trên ứng dụng này và nhấn Lưu & Đồng bộ Cấu hình.
