Mã nguồn Google Apps Script chuẩn (Tự tạo 3 Sheet)

Tự động khởi tạo sheet: SanPham, DonHang, KhachHang

Hướng dẫn cài đặt nhanh (chỉ 1 phút):

  1. Tạo một file Google Sheets mới trên Google Drive của bạn.
  2. Trên thanh menu, chọn Tiện ích mở rộng (Extensions) → Apps Script.
  3. Xóa hết code mặc định và dán toàn bộ đoạn code bên dưới vào, sau đó nhấn Lưu (Ctrl+S).
  4. Nhấn nút Triển khai (Deploy) → Tùy chọn triển khai mới (New deployment).
  5. Chọn loại là Ứng dụng web (Web app). Phần Người có quyền truy cập (Who has access) chọn Bất kỳ ai (Anyone) → Nhấn Triển khai.
  6. Copy đường dẫn URL ứng dụng web dán vào ô cấu hình trên ứng dụng này!
